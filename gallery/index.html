Accessibility Principles (POUR)

1. Perceivable

All tokens meet WCAG AA contrast ratios (minimum 4.5:1 for body text, 6.4:1+ on all badges). Status is never shown by colour alone.

2. Operable

100% keyboard operable via Tab, Enter, Space, Escape, and Arrow keys with a high-contrast double blue focus ring.

3. Understandable

Clear labels, hints, and inline error messages linked via aria-describedby and announced to screen readers.

4. Robust

Semantic HTML5 first with WAI-ARIA Authoring Practices for Dialogs, Tabs, Sortable Tables, and Live Regions.

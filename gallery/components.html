Quick Start: Include Aksha UI in Your Project

Paste these lines inside your HTML once to load all styles, design tokens, and interactive accessibility scripts. After that, any component snippet below will work out of the box:

1. Button (.ak-button)

Keyboard & ARIA: Enter / Space activates. Icon-only buttons require aria-label. Start labels with a verb ("Check out", "Return book").

Do: Start with an action verb and include aria-label on icon buttons.
Don't: Remove focus outlines or use vague text like "Click here".
<button class="ak-button primary">Check out</button>

2. TextField (.ak-textfield)

Keyboard & ARIA: Uses explicit <label for>, links hint and error via aria-describedby, and sets aria-invalid="true" on error.

Search by book title, author, or ISBN
Enter a 10 or 13 digit ISBN ISBN must be 10 or 13 digits. You entered 9.
<div class="ak-field"> <label class="ak-label" for="book-title">Book title</label> <input class="ak-textfield" id="book-title" type="text" required> </div>

3. Select (.ak-select)

Keyboard & ARIA: Native <select> with <label for>; supports Up/Down arrows and Space to expand.

<label class="ak-label" for="cat">Category</label> <select class="ak-select" id="cat"><option>Software</option></select>

4. Checkbox (.ak-checkbox)

Keyboard & ARIA: Space toggles checked state. Native checkbox paired with explicit label.

<label class="ak-checkbox-wrapper"> <input type="checkbox" class="ak-checkbox"> Available copies only </label>

5. Badge (.ak-badge)

Accessibility Rule: Never communicate status by colour alone—always include descriptive text ("Due in 3 days", "Overdue by 2 days").

Available (2 copies) Due in 10 days Due today Overdue by 2 days
<span class="ak-badge danger">Overdue by 2 days</span>

6. Alert & Toast (.ak-alert / showToast())

Keyboard & ARIA: Uses role="status" (polite) for confirmations and role="alert" for errors.

You can borrow up to 3 books. Return one first.
showToast('Checked out. Due on 28 Aug 2026.', 'success');

7. Modal Dialog (.ak-dialog)

Keyboard & ARIA: role="dialog", aria-modal="true", aria-labelledby. Traps Tab focus inside, closes on Esc, and returns focus to the trigger button.

Clean Code

Author: Robert C. Martin | ISBN: 9780132350884

Available

<div id="myDialog" class="ak-dialog" role="dialog" aria-labelledby="dlgTitle" hidden> <h2 id="dlgTitle">Confirm Action</h2> <button class="ak-button secondary" data-dialog-close>Close</button> </div>

8. Card (.ak-card)

ARIA Note: Contains a semantic heading and explicit action button; avoids wrapping the entire card in a link.

Available

Designing Data-Intensive Applications

Martin Kleppmann • Software

<article class="ak-card"> <h3>Clean Code</h3> <button class="ak-button primary">View details</button> </article>

9. Sortable Data Table (.ak-table)

Keyboard & ARIA: Includes <caption>, <th scope="col">, and aria-sort. Focus any header and press Enter or Space to sort.

Sample Library Catalog (Click or press Enter on headers to sort)
Title Author Year
Clean Code Robert C. Martin 2008
The Pragmatic Programmer Andrew Hunt 1999
Designing Data-Intensive Applications Martin Kleppmann 2017
<table class="ak-table"> <caption>Book Loans</caption> <thead><tr><th scope="col" data-sort aria-sort="none">Title</th></tr></thead> </table>

10. Accessible Tabs (.ak-tabs)

Keyboard & ARIA: Uses role="tablist", role="tab", role="tabpanel", aria-selected, and roving tabindex. Use Left/Right arrows and Home/End keys.

Showing active loans with due-date badges.

Showing previously returned books.

<div class="ak-tabs"> <div role="tablist" aria-label="Sections"> <button role="tab" aria-selected="true" aria-controls="p1" id="t1" tabindex="0">Tab 1</button> </div> <div id="p1" role="tabpanel" aria-labelledby="t1">Content</div> </div>
